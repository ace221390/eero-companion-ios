# EeroCompanion iOS

## To get the IPA:
1. Push this folder to a **new private GitHub repo**
2. Go to Actions tab → "Build EeroCompanion IPA" → Run workflow
3. When it finishes (2-3 min) → click the run → download `EeroCompanion-unsigned-ipa`
4. Install the IPA using **AltStore** or **Sideloadly** on your iPad

## Install IPA on iPad (AltStore method — free, no jailbreak):
1. Install AltStore on your PC/Mac from altstore.io
2. Install AltStore on your iPad via AltStore desktop app
3. Open AltStore on iPad → My Apps → + → pick EeroCompanion-unsigned.ipa
4. Done. Re-sign every 7 days (free Apple ID limit) or use a paid dev account for 1 year.

## Install IPA on iPad (Sideloadly method — Windows friendly):
1. Download Sideloadly from sideloadly.io
2. Connect iPad via USB
3. Open Sideloadly → drag IPA in → enter your Apple ID → Start
4. On iPad: Settings → General → VPN & Device Management → trust your Apple ID
